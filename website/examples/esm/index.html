Date Range Picker Integrations

TypeScript & ES modules

Import the constructor, stylesheet and option types directly from the package. The picker writes the applied range back to the input.

App source

main.ts
import DateRangePicker, { type Options } from 'daterangepicker';
import 'daterangepicker/daterangepicker.css';

const input = document.querySelector<HTMLInputElement>('#dates')!;
const options: Options = { singleCalendar: true };
new DateRangePicker(input, options);
index.html

Run this example locally

Serve the website directory over HTTP and open /examples/esm/. To edit the app, change its files in example/integrations/esm and run these commands from example/integrations.

npm ci
npm run build
