Quick start

Choose how to load the picker. Each example uses the same JavaScript component and stylesheet.

Download the v4 package into your app folder.

Terminal
npm install ./daterangepicker-4.0.2.tgz
index.html
<link rel="stylesheet" href="./daterangepicker.css">
<label for="dates">Report dates</label>
<input id="dates">

<script src="./daterangepicker.js"></script>
<script>
  new DateRangePicker('#dates');
</script>
Place the JavaScript and CSS beside your page.Run example ↗

Local v4 files JavaScript ↓ ES module ↓ CSS ↓

Serve the files from a CDN

These jsDelivr URLs pin both files to version 4.0.2. They become available when that version is published to npm.

index.html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/daterangepicker@4.0.2/daterangepicker.css">
<label for="dates">Report dates</label>
<input id="dates">

<script src="https://cdn.jsdelivr.net/npm/daterangepicker@4.0.2/daterangepicker.js"></script>
<script>
  new DateRangePicker('#dates');
</script>
